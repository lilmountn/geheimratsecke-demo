# Geheimratsecke – öffentliche Demo

- **Demo:** <https://lilmountn.github.io/geheimratsecke-demo/>
- **Repository:** <https://github.com/lilmountn/geheimratsecke-demo>

Dies ist ein statischer, interaktiver Prototyp. Er hat kein Bestellsystem und übermittelt keine Formulareingaben. Die Demo-Vormerkung ist keine Bestellung oder echte Reservierung.

## Sortiment und Preise

Die 19 angezeigten Artikel sind als geplantes Sortiment bestätigt. Das bestätigt weder Verfügbarkeit noch Lagerbestand. Die angezeigten Preise bleiben unverbindliche, unbestätigte Vorschläge; Pfand ist separat und noch zu bestätigen. Die CSV mit den detaillierten Produktvorschlägen wird nicht öffentlich bereitgestellt.

Alkoholische Artikel sind markiert. Die Demo führt keine Online-Altersprüfung durch; die Altersprüfung muss bei einer tatsächlichen Abgabe vor Ort erfolgen.

## Veröffentlichung

GitHub Actions veröffentlicht bei jedem Push auf main automatisch index.html und das benötigte Logo unter assets/. Die Produktvorschlags-CSV wird nicht in die Website aufgenommen.

Vor einer echten Nutzung mit Bestellungen sind unter anderem ein Backend, eine bestätigte Bestands- und Preisquelle, ein angemessener Datenschutzprozess und ein rechtskonformer Ablauf für altersbeschränkte Artikel erforderlich.
